# 向量数据库对比

## ChromaDB

ChromaDB 是一个开源的向量数据库，专为 AI 应用设计。

### 特点
- 轻量级，Python 原生支持
- 支持内存模式和持久化存储
- 内置多种 embedding 函数
- 支持元数据过滤
- 适合中小规模应用（十万到百万级向量）

### 使用场景
- RAG 应用
- 语义搜索
- 文档相似度匹配

### 安装
```bash
pip install chromadb
```

## FAISS

Facebook AI Similarity Search，由 Meta 开发。

### 特点
- C++ 实现，Python 接口
- 支持 GPU 加速
- 多种索引算法（IVF、HNSW、PQ）
- 不内置持久化（需手动序列化）

### 使用场景
- 大规模向量检索（百万到十亿级）
- 需要极致性能的场景

## Pinecone

全托管的向量数据库服务。

### 特点
- 无需运维
- 自动扩展
- 实时索引更新
- 内置监控

### 缺点
- 付费服务
- 数据需上传到云端

## Milvus

开源云原生向量数据库。

### 特点
- 分布式架构
- 支持十亿级向量
- 多种索引类型
- 完整的 CRUD 支持

### 使用场景
- 企业级应用
- 需要高可用和扩展性
